# Project Context: AMD LegalTech MVP (AI-Assistant for Lawyers & Bankruptcy Trustees)

## Domain & Core Value
We are building a B2B LegalTech SaaS for Russian litigation lawyers and bankruptcy trustees (арбитражные управляющие).
Core principles:
1. **Zero Data Entry**: Lawyers never fill out forms manually. Case cards (Case Number, Court, Judge, Parties, Deadlines) are created automatically either by uploading a PDF court ruling or entering a case number (e.g., А40-12345/2026).
2. **Strict Fact-Checking (No Hallucinations)**: Every AI summary statement or deadline MUST include an exact quote (`exact_quote`) and page/paragraph reference (`page_number`) from the source PDF.
3. **Deadline Radar**: Automatic calculation and highlighting of procedural deadlines (1-3 days for EFRSB/Fedresurs publications, 10/30 days for appeals).

## Tech Stack
- **Backend**: Python 3.11+, FastAPI, Pydantic v2, SQLAlchemy 2.0 (SQLite for local MVP, ready for PostgreSQL).
- **Document Parsing**: `PyMuPDF` (`fitz`) for fast native PDF text extraction with page coordinates; regex + LLM structured outputs for header/metadata extraction.
- **Court Scraping**: Modular provider architecture (`BaseCourtProvider`) supporting:
  1. `DocumentMetadataProvider` (extracts case info directly from uploaded PDFs).
  2. `PlaywrightKadProvider` (headless browser parser for kad.arbitr.ru / sudrf.ru).
  3. `MockCourtProvider` (realistic Russian arbitration case generator for instant UI testing without hitting rate limits).
- **AI / LLM**: OpenAI-compatible SDK. Yandex AI Studio (YandexGPT / Alice AI) подключается через `OPENAI_BASE_URL=https://ai.api.cloud.yandex.net/v1`, `OPENAI_PROJECT=<folder_id>` и `OPENAI_MODEL=gpt://<folder_id>/aliceai-llm`. Тот же клиент остаётся совместим с OpenAI, DeepSeek и Ollama. Извлечение идёт конвейером «код → модель → код»: regex готовит реквизиты, модель заполняет только факты из PDF, код проверяет цитаты, пересчитывает даты и подставляет справку.

## Coding Guidelines
- Always use strict typing (Python type hints, Pydantic models).
- Handle Russian encodings (UTF-8) and Russian legal terminology accurately (Определение, Решение, Постановление, Резолютивная часть, Истец, Ответчик, Должник, Кредитор, Обособленный спор).
- Keep business logic modular: `app/services/pdf_parser.py`, `app/services/ai_extractor.py`, `app/services/legal_knowledge.py` (детерминированная база норм РФ), `app/services/court_scraper.py`, `app/services/storage.py` (SQLite `backend/lawtech.db`).
- Web UI lives in `app/static/` (`index.html`, `app.js`) and is served at `GET /`.

## Что изменено

- У разобранного PDF появилось поле `token_usage` (`prompt_tokens`, `completion_tokens`, `total_tokens`). Расход читается из `completion.usage`, пишется в лог и показывается рядом с бейджем LLM и в «Подробностях» (`3 840 ток.`). Старые дела без этого поля бейдж не рисуют.
- Пример JSON в запросе к модели сериализуется без отступов. Повторы между системной инструкцией и правилами ответа убраны. Запрет выдумывать факты, правила дат, цитат, ФИО и отсечения шаблона сохранены.
- Цитата, которая начинается на одной странице и заканчивается на следующей, считается найденной. Ложное «⚠ проверить текст» на таком стыке не ставится.
- Срок с той же цитатой или с тем же сроком и той же сутью, что уже есть в поручении с исполнителем, в `deadlines` не дублируется.
- Первая фраза сводки больше не склоняет название суда: `Дело № … (Арбитражный суд …, судья …):`. Связки `ст. 213.4, 213.9 ФЗ-127` и `ст. 65, 223 АПК РФ` становятся одной ссылкой.

    CaseDetailResponse,

MAX_FILES = 10
MAX_BYTES = 30 * 1024 * 1024

@app.get("/api/health", response_model=HealthResponse, tags=["system"])
async def health() -> HealthResponse:

    return HealthResponse(

        llm_model=extractor.model if extractor.is_configured else None,
        llm_provider=extractor.provider_name,

@app.post("/api/documents/upload", response_model=DocumentUploadResponse, tags=["documents"])
async def upload_documents(
    files: list[UploadFile] = File(..., description="Один или несколько PDF судебных актов"),
) -> DocumentUploadResponse:
    """Разобрать PDF, проверить цитаты и сохранить дело в SQLite."""

    if not files:
        raise HTTPException(status_code=400, detail="Прикрепите хотя бы один PDF")
    if len(files) > MAX_FILES:
        raise HTTPException(
            status_code=400,
            detail=f"За один запрос можно загрузить не больше {MAX_FILES} файлов",
        )

    documents: list[DocumentUploadItem] = []
    for upload in files:
        content = await upload.read()
        filename = upload.filename or "document.pdf"
        if len(content) > MAX_BYTES:
            raise HTTPException(status_code=413, detail=f"{filename}: файл больше 30 МБ")
        if not content.startswith(b"%PDF"):
            raise HTTPException(status_code=400, detail=f"{filename}: ожидается PDF")
        try:
            parsed = await asyncio.to_thread(parser.parse, content)
            outcome = await asyncio.to_thread(extractor.extract, parsed)
        except PdfParseError as exc:
            raise HTTPException(status_code=400, detail=f"{filename}: {exc.message}") from exc
        item = DocumentUploadItem(
            filename=filename,
            page_count=len(parsed.pages),
            pages=parsed.pages,
            regex_metadata=parsed.metadata,
            analysis=outcome.analysis,
            extraction_mode=outcome.extraction_mode,
            warnings=outcome.warnings,
            token_usage=outcome.token_usage,
        )
        store.save_document(item, content)
        documents.append(item)
    return DocumentUploadResponse(
        documents=documents,
        case_id=documents[0].case_id if documents else None,
    )


@app.post("/api/cases/fetch-by-number", response_model=CaseCard, tags=["cases"])
async def fetch_case_by_number(payload: FetchCaseRequest) -> CaseCard:
    """Подтянуть карточку по номеру дела и сохранить её в радаре."""

    try:
        card = await scraper.fetch_case_by_number(payload.case_number)
    except CourtScraperError as exc:
        raise HTTPException(status_code=502, detail=exc.message) from exc
    card.case_id = store.save_court_card(card)
    return card


@app.get("/api/cases", response_model=list[CaseListItem], tags=["cases"])
async def list_cases() -> list[CaseListItem]:
    """Список дел: сначала срочные, затем ближайшие даты."""

    return store.list_cases()


@app.get("/api/cases/{case_id}", response_model=CaseDetailResponse, tags=["cases"])
async def get_case(case_id: int) -> CaseDetailResponse:
    """Полная карточка и все PDF этого дела."""

    found = store.get_case(case_id)
    if found is None:
        raise HTTPException(status_code=404, detail="Дело не найдено")
    return found


@app.patch(
    "/api/cases/{case_id}/tasks/{task_key}",
    response_model=TaskStateUpdateResponse,
    tags=["cases"],
)
async def update_task(case_id: int, task_key: str, payload: TaskStateUpdateRequest) -> TaskStateUpdateResponse:
    """Отметить задачу выполненной или посчитать срок от даты получения."""

    try:
        return store.update_task_state(case_id, task_key, payload.is_done, payload.receipt_date)
    except LookupError as exc:
        raise HTTPException(status_code=404, detail=str(exc)) from exc
    except ValueError as exc:
        raise HTTPException(status_code=400, detail=str(exc)) from exc


@app.get("/api/documents/{doc_id}/pdf", tags=["documents"])
async def download_pdf(doc_id: int) -> FileResponse:
    """Оригинал загруженного PDF."""

    path = store.pdf_path(doc_id)
    if not path.is_file():
        raise HTTPException(status_code=404, detail="PDF не найден")
    return FileResponse(path, media_type="application/pdf", filename=path.name)


@app.delete("/api/cases/{case_id}", tags=["cases"])
async def delete_case(case_id: int) -> dict[str, bool]:
    """Удалить дело и привязанные документы."""

    if not store.delete_case(case_id):
        raise HTTPException(status_code=404, detail="Дело не найдено")
    return {"deleted": True}


@app.get("/", include_in_schema=False)
async def index() -> FileResponse:
    return FileResponse(STATIC_DIR / "index.html")


app.mount("/static", StaticFiles(directory=STATIC_DIR), name="static")

def _tidy(value: str) -> str:
    return " ".join(value.translate(_DASH_TO_HYPHEN).split())

    if value is None:

def ocr_search_copy(text: str) -> str:
    """Копия только для поиска. Исходный текст страницы для подсветки не меняется."""

    normalized = text.translate(_DASH_TO_HYPHEN)

    def fix_token(match: re.Match[str]) -> str:
        token = match.group(0)
        has_cyrillic = re.search(r"[А-Яа-яЁё]", token) is not None
        has_latin = re.search(r"[A-Za-z]", token) is not None
        if has_cyrillic and has_latin:
            return token.translate(_OCR_LATIN_TO_CYR)
        return token

    return re.sub(r"\S+", fix_token, normalized)


def _match_to_iso(match: re.Match[str]) -> str:
    if match.group(1):
        day, month, year = match.group(1).split(".")
        return f"{year}-{month}-{day}"
    day, month, year = match.group(2), match.group(3), match.group(4)
    return f"{year}-{_MONTHS[month.lower()]}-{int(day):02d}"


def canonical_case_number(value: str) -> str:
    """А21-11942/2026: без пробелов, кириллическая А, обычный дефис, верхний регистр."""

    if not re.search(r"\d", value):
        return " ".join(value.split())
    cleaned = value.translate(_DASH_TO_HYPHEN)
    cleaned = re.sub(r"\s+", "", cleaned)
    return cleaned.upper().replace("A", "А")


def _canonical_case_number(value: str) -> str:
    return canonical_case_number(value)


class SmartPDFParser:
    """Извлекает постраничный текст и реквизиты первой страницы без LLM."""

    def parse(self, file_bytes: bytes) -> PdfParseResult:
        if not file_bytes:
            raise PdfParseError("Пустой файл")
        if not file_bytes.startswith(b"%PDF"):
            raise PdfParseError("Файл не является PDF")

        try:
            document = fitz.open(stream=file_bytes, filetype="pdf")
        except Exception as exc:
            raise PdfParseError(f"Не удалось открыть PDF: {exc}") from exc

        try:
            if document.needs_pass:
                raise PdfParseError("PDF защищён паролем и не может быть прочитан")
            if document.page_count == 0:
                raise PdfParseError("PDF не содержит страниц")

            pages = [
                PageText(page=index, text=page.get_text("text") or "")
                for index, page in enumerate(document, start=1)
            ]
        finally:
            document.close()

        return PdfParseResult(pages=pages, metadata=self._extract_metadata(pages))

    def _extract_metadata(self, pages: list[PageText]) -> RegexMetadata:
        first_page = pages[0].text if pages else ""
        full_text = "\n".join(page.text for page in pages)
        search_first = ocr_search_copy(first_page)
        search_full = ocr_search_copy(full_text)

        case_number = self._first_group(_CASE_NUMBER_RE, search_first)
        if case_number is None:
            case_number = self._first_group(_CASE_NUMBER_RE, search_full)
        if case_number is not None:
            case_number = _canonical_case_number(case_number)

        return RegexMetadata(
            case_number=case_number,
            dates=self._dates(search_first) or self._dates(search_full),
            act_date=self._act_date(search_first),
            inns=self._unique(_INN_RE.findall(search_first) or _INN_RE.findall(search_full)),
            ogrns=self._unique(_OGRN_RE.findall(search_first) or _OGRN_RE.findall(search_full)),
            snils_list=self._unique(_SNILS_RE.findall(search_full)),
            sro_names=self._unique(_tidy(item) for item in _SRO_RE.findall(search_full)),
            court_name=_optional_text(self._court_name(search_first) or self._court_name(search_full)),
            judge_name=_optional_text(
                self._first_group(_JUDGE_RE, search_first) or self._first_group(_JUDGE_RE, search_full)
            ),
            document_type=self._document_type(search_first) or self._document_type(search_full),
            parties=self._parties(search_full),
        )

    @classmethod
    def _act_date(cls, first_page: str) -> Optional[str]:
        """Дата вынесения акта в шапке первой страницы, без дат законов, рождения и ЭП."""

        lowered = first_page.lower()
        cut = min(len(first_page), 2200)
        for marker in ("установил", "рассмотрев"):
            index = lowered.find(marker)
            if 0 <= index < cut:
                cut = index
        header = first_page[:cut]
        for match in _ANY_DATE_RE.finditer(header):
            if cls._ignored_date(header, match.start(), match.end()):
                continue
            return _match_to_iso(match)
        return None

    @staticmethod
    def _ignored_date(text: str, start: int, end: int) -> bool:
        window = text[max(0, start - 48): end + 24].lower()
        prefix = text[max(0, start - 12): start].lower()
        if any(marker in window for marker in ("рожден", "электронн", "подпись действительн", "пленум")):
            return True
        if re.search(r"от\s*$", prefix):
            return True
        if "закон" in window and re.search(r"от\s*$", prefix):
            return True
        return False

    @staticmethod
    def _first_group(pattern: re.Pattern[str], text: str) -> Optional[str]:
        match = pattern.search(text)
        if match is None:
            return None
        return match.group(1).strip()

    @classmethod
    def _dates(cls, text: str) -> list[str]:
        found: list[str] = []
        for match in _ANY_DATE_RE.finditer(text):
            if match.group(1):
                found.append(match.group(1))
                continue
            day, month, year = match.group(2), match.group(3), match.group(4)
            found.append(f"{int(day):02d}.{_MONTHS[month.lower()]}.{year}")
        return cls._unique(found)

    @staticmethod
    def _court_name(text: str) -> Optional[str]:
        for line in text.splitlines():
            cleaned = " ".join(line.split())
            if "АРБИТРАЖНЫЙ СУД" in cleaned.upper() and 10 < len(cleaned) < 180:
                return cleaned
            if re.search(r"районный суд|городской суд|областной суд|верховный суд", cleaned, re.IGNORECASE):
                return cleaned
        return None

    @staticmethod
    def _document_type(text: str) -> Optional[DocumentType]:
        head = text[:2500].lower()
        found: list[tuple[int, DocumentType]] = []
        for needle, label in (
            ("постановление", "Постановление"),
            ("требование кредитора", "Требование кредитора"),
            ("выписка", "Выписка"),
            ("определение", "Определение"),
            ("решение", "Решение"),
        ):
            index = head.find(needle)
            if index >= 0:
                found.append((index, label))
        if not found:
            return None
        return min(found)[1]

    @classmethod
    def _parties(cls, text: str) -> list[PartyInfo]:
        parties: list[PartyInfo] = []
        seen: set[str] = set()
        for match in _PARTY_RE.finditer(text):
            name = _tidy(match.group(2)).strip(" ,.;")
            key = name.lower().replace("ё", "е")
            if len(name) < 3 or key in seen:
                continue
            seen.add(key)
            window = text[match.end(): match.end() + 120]
            inn_match = _INN_RE.search(window)
            ogrn_match = _OGRN_RE.search(window)
            role = cls._role(match.group(1))
            prefix = text[max(0, match.start() - 48): match.start()].lower().replace("ё", "е")
            if role == "Должник" and "управляющ" in prefix:
                role = "Финансовый управляющий"
            parties.append(
                PartyInfo(
                    role=role,
                    name=name,
                    inn=inn_match.group(1) if inn_match else None,
                    ogrn=ogrn_match.group(1) if ogrn_match else None,
                )
            )
        return parties

    @staticmethod
    def _role(token: str) -> PartyRole:
        lowered = token.lower()
        if lowered.startswith("ист"):
            return "Истец"
        if lowered.startswith("ответ"):
            return "Ответчик"
        if lowered.startswith("долж"):
            return "Должник"
        if lowered.startswith("кред"):
            return "Кредитор"
        return "Третье лицо"

    @staticmethod
    def _unique(values: list[str]) -> list[str]:
        result: list[str] = []
        for value in values:
            if value not in result:
                result.append(value)
        return result

Конечная дата суда («до 11 мая 2027 года», «до 06 ноября 2026 года»): anchor_event=fixed_date, due_date=YYYY-MM-DD, не считай act_date+N. «в течение месяца»: months_limit=1, days_limit=0. «с даты получения»: receipt_date, due_date=null. Рабочие дни: days_type=business, иначе calendar. Пропись: девяти=9, четырнадцати=14, пяти=5, семи=7, пятнадцати=15.
exact_quote дословно из [PAGE N], page_number = N. regex_hints — подсказка; при расхождении верь тексту страницы.
role: Истец | Ответчик | Должник | Кредитор | Третье лицо | СРО АУ | Финансовый управляющий.
document_type: Определение | Решение | Постановление | Требование кредитора | Выписка.
"""

class AILegalExtractor:
    """Структурирует судебный акт через OpenAI-совместимый API или локальные regex."""

    def __init__(self) -> None:
        load_dotenv()
        self.api_key = os.getenv("OPENAI_API_KEY", "").strip()
        self.base_url = os.getenv("OPENAI_BASE_URL", "").strip()
        self.project = os.getenv("OPENAI_PROJECT", "").strip()
        self.model = os.getenv("OPENAI_MODEL", "gpt-4o-mini").strip() or "gpt-4o-mini"
        self._last_llm_raw = ""

    @property
    def is_configured(self) -> bool:
        return bool(self.api_key)

    @property
    def provider_name(self) -> str:
        if not self.is_configured:
            return "fallback"
        if "yandex" in self.base_url.lower():
            return "yandex"
        return "openai-compatible"

    def extract(self, parsed: PdfParseResult) -> ExtractionOutcome:
        token_usage: Optional[dict[str, int]] = None
        if not self.is_configured:
            analysis = build_fallback_analysis(parsed)
            warnings = ["OPENAI_API_KEY не задан: карточка собрана регулярными выражениями, без LLM."]
            warnings.extend(_fallback_warnings(parsed, analysis))
            mode = "fallback"
        else:
            try:
                analysis, llm_notes, token_usage = self._call_llm(parsed)
                warnings = list(llm_notes)
                mode = "llm"
            except Exception as exc:
                self._log_llm_failure(exc)
                analysis = build_fallback_analysis(parsed)
                warnings = [
                    f"LLM недоступен ({_safe_error(exc)}). Карточка собрана регулярными выражениями.",
                    *_fallback_warnings(parsed, analysis),
                ]
                mode = "fallback"
                token_usage = None
        warnings.extend(apply_layer3(parsed, analysis))
        return ExtractionOutcome(
            analysis=analysis,
            extraction_mode=mode,
            warnings=warnings,
            token_usage=token_usage,
        )

    def _call_llm(self, parsed: PdfParseResult) -> tuple[DocumentAnalysisResult, list[str], Optional[dict[str, int]]]:
        self._last_llm_raw = ""
        client = OpenAI(**self._client_kwargs())
        example = json.dumps(_RESPONSE_EXAMPLE, ensure_ascii=False, separators=(",", ":"))
        messages = [
            {"role": "system", "content": _SYSTEM_PROMPT},
            {
                "role": "user",
                "content": (
                    "Верни один JSON-объект строго в такой форме. Имена полей не переименовывай.\n"
                    f"{_RESPONSE_RULES}\n"
                    f"Пример:\n{example}\n\n"
                    f"regex_hints:\n{parsed.metadata.model_dump_json()}\n\n"
                    f"Текст документа:\n{_prompt_text(parsed.pages)}"
                ),
            },
        ]
        completion = self._complete(client, messages)
        content = completion.choices[0].message.content or ""
        self._last_llm_raw = content
        fallback = build_fallback_analysis(parsed)
        payload = _sanitize_llm_payload(_unwrap_payload(_load_json(content)), parsed, fallback)
        notes = [str(item) for item in payload.pop("_sanitize_warnings", [])]
        usage = _read_token_usage(completion)
        return DocumentAnalysisResult.model_validate(payload), notes, usage

    def _log_llm_failure(self, exc: Exception) -> None:
        raw = _public_llm_text(getattr(self, "_last_llm_raw", ""))
        if isinstance(exc, ValidationError):
            logger.warning(
                "Ответ LLM не прошёл проверку DocumentAnalysisResult. Сырой ответ: %s. Поля: %s",
                raw,
                _validation_field_list(exc),
            )
            return
        logger.warning("LLM extraction failed: %s. Сырой ответ: %s", _safe_error(exc), raw)

    def _client_kwargs(self) -> dict[str, object]:
        kwargs: dict[str, object] = {"api_key": self.api_key, "timeout": 120.0}
        if self.base_url:
            kwargs["base_url"] = self.base_url
        if self.project:
            kwargs["project"] = self.project
        return kwargs

    def _complete(self, client: OpenAI, messages: list[dict[str, str]]) -> object:
        try:
            return client.chat.completions.create(
                model=self.model,
                temperature=0,
                messages=messages,
                response_format={"type": "json_object"},
            )
        except Exception as exc:
            if not _response_format_rejected(exc):
                raise
            logger.info("Провайдер не принял response_format, повтор без него")
            return client.chat.completions.create(
                model=self.model,
                temperature=0,
                messages=messages,
            )


def build_fallback_analysis(parsed: PdfParseResult) -> DocumentAnalysisResult:
    """Собирает карточку из текста PDF, если LLM не вызывается."""

    pages = parsed.pages
    metadata = parsed.metadata
    full_text = "\n".join(page.text for page in pages)
    if not full_text.strip():
        return DocumentAnalysisResult(
            case_number=metadata.case_number or "НЕ ИЗВЛЕЧЁН",
            court_name=metadata.court_name or "Суд не указан в текстовом слое",
            judge_name=metadata.judge_name,
            document_type="Выписка",
            document_date=None,
            stage_code="general_arbitration_dispute",
            case_stage=STAGE_TITLES["general_arbitration_dispute"],
            act_date=metadata.act_date,
            parties=metadata.parties,
            verdict_summary=(
                "Текстовый слой PDF пуст. Вероятно, это скан без OCR, "
                "поэтому резолютивная часть и сроки не извлечены."
            ),
            financial_claims=[],
            deadlines=[],
            legal_basis=[],
            key_points=[],
        )

    document_type = _refine_document_type(metadata.document_type, full_text)
    stage_code, case_stage = _classify_stage(full_text)
    act_date = metadata.act_date
    document_date = _iso_to_ru(act_date) or (metadata.dates[0] if metadata.dates else None)
    verdict = _verdict_summary(pages, document_type)
    return DocumentAnalysisResult(
        case_number=metadata.case_number or "НЕ ИЗВЛЕЧЁН",
        court_name=metadata.court_name or "Суд не указан в текстовом слое",
        judge_name=metadata.judge_name,
        document_type=document_type,
        document_date=document_date,
        stage_code=stage_code,
        case_stage=case_stage,
        act_date=act_date,
        parties=metadata.parties,
        verdict_summary=verdict,
        financial_claims=_financial_claims(metadata.parties, pages),
        next_hearing=_next_hearing(pages),
        court_orders=_court_orders(pages),
        deadlines=_deadlines(pages, document_type, act_date or document_date),
        legal_basis=_legal_basis(full_text),
        key_points=_key_points(pages),
    )


def _fallback_warnings(parsed: PdfParseResult, analysis: DocumentAnalysisResult) -> list[str]:
    warnings: list[str] = []
    if not any(page.text.strip() for page in parsed.pages):
        warnings.append("В PDF нет текстового слоя.")
    elif parsed.metadata.document_type is None and analysis.document_type == "Выписка":
        warnings.append("Тип акта по заголовку не найден, в карточке указана «Выписка».")
    if analysis.case_number == "НЕ ИЗВЛЕЧЁН":
        warnings.append("Арбитражный номер дела на первой странице не найден.")
    return warnings


def _refine_document_type(current: Optional[DocumentType], text: str) -> DocumentType:
    if current is not None:
        return current
    lowered = text.lower()
    if "определил" in lowered:
        return "Определение"
    if "постановил" in lowered:
        return "Постановление"
    if re.search(r"\bрешил\b", lowered):
        return "Решение"
    return "Выписка"


def _verdict_summary(pages: list[PageText], document_type: DocumentType) -> str:
    for page in pages:
        section = _between(page.text, ("определил", "решил", "постановил"), ("судья",))
        sentences = [item for item in _sentences(section) if not _is_marker(item)]
        if sentences:
            chosen = sentences[:1] if len(sentences[0]) >= 40 else sentences[:2]
            summary = re.sub(
                r"^(?:определил|решил|постановил)\s*:\s*",
                "",
                " ".join(chosen),
                count=1,
                flags=re.IGNORECASE,
            )
            return summary[:700]
    for page in pages:
        sentences = _sentences(page.text)
        if sentences:
            return sentences[0][:700]
    return f"Резолютивная часть в тексте акта «{document_type}» не выделена."


def _financial_claims(parties: list, pages: list[PageText]) -> list[str]:
    amounts: list[str] = []
    for page in pages:
        for sentence in _sentences(page.text):
            found = _MONEY_RE.findall(sentence)
            if not found:
                continue
            amount = found[0]
            claim = _format_claim(parties, amount, sentence)
            if claim not in amounts:
                amounts.append(claim)
    return amounts[:8]


def _format_claim(parties: list, amount: str, sentence: str) -> str:
    creditors = [party.name for party in parties if party.role == "Кредитор"]
    debtors = [party.name for party in parties if party.role == "Должник"]
    plaintiffs = [party.name for party in parties if party.role == "Истец"]
    defendants = [party.name for party in parties if party.role == "Ответчик"]
    left = (creditors or plaintiffs or [None])[0]
    right = (debtors or defendants or [None])[0]
    money = amount if re.search(r"руб|₽", amount, re.IGNORECASE) else f"{amount} руб."
    if left and right:
        return f"{left} → {right}: {money}"
    compact = re.sub(r"\s+", " ", sentence).strip()
    return compact[:400]


def _deadlines(pages: list[PageText], document_type: DocumentType, document_date: Optional[str]) -> list[DeadlineItem]:
    items: list[DeadlineItem] = []
    publication = _sentence_quote(pages, re.compile(r"ефрсб|федресурс", re.IGNORECASE))
    if publication is not None:
        days = _days_near(publication.exact_quote, default=3)
        business = "рабоч" in publication.exact_quote.lower()
        items.append(
            DeadlineItem(
                description="Публикация на ЕФРСБ",
                due_date=None,
                days_limit=days,
                days_type="business" if business else "calendar",
                anchor_event="act_date",
                urgency="critical" if days <= 10 else "normal",
                source_quote=publication,
            )
        )

    appeal = _sentence_quote(pages, re.compile(r"апелляционн|обжалован", re.IGNORECASE))
    if appeal is not None:
        default_days = 10 if document_type == "Определение" else 30
        days = _days_near(appeal.exact_quote, default=default_days)
        items.append(
            DeadlineItem(
                description="Подача апелляционной жалобы",
                due_date=None,
                days_limit=days,
                days_type="business" if "рабоч" in appeal.exact_quote.lower() else "calendar",
                anchor_event="receipt_date" if re.search(r"получен", appeal.exact_quote, re.IGNORECASE) else "act_date",
                urgency="critical" if days <= 10 else "normal",
                source_quote=appeal,
            )
        )
    return items


def _legal_basis(text: str) -> list[str]:
    found: list[str] = []
    for match in _LAW_RE.finditer(text):
        clause = _readable(match.group(0)).strip(" ,.;")
        if clause and clause not in found:
            found.append(clause)
    return found[:12]


def _key_points(pages: list[PageText]) -> list[QuoteReference]:
    points: list[QuoteReference] = []
    for page in pages:
        section = _between(page.text, ("установил", "установила"), ("определил", "решил", "постановил"))
        for sentence in _sentences(section):
            if _is_marker(sentence):
                continue
            quote = _exact_substring(page.text, sentence)
            if quote is None:
                continue
            quote = _without_marker(page.text, quote)
            points.append(QuoteReference(page_number=page.page, exact_quote=quote[:700]))
            if len(points) >= 4:
                return points
    return points


def _sentence_quote(pages: list[PageText], pattern: re.Pattern[str]) -> Optional[QuoteReference]:
    for page in pages:
        for sentence in _sentences(page.text):
            if not pattern.search(sentence):
                continue
            quote = _exact_substring(page.text, sentence)
            if quote is not None:
                return QuoteReference(page_number=page.page, exact_quote=quote[:700])
    return None


def _between(text: str, starts: tuple[str, ...], ends: tuple[str, ...]) -> str:
    lowered = text.lower()
    start_at = -1
    start_len = 0
    for marker in starts:
        index = lowered.find(marker)
        if index >= 0 and (start_at < 0 or index < start_at):
            start_at = index
            start_len = len(marker)
    if start_at < 0:
        return ""
    end_at = -1
    for marker in ends:
        index = lowered.find(marker, start_at + start_len)
        if index >= 0 and (end_at < 0 or index < end_at):
            end_at = index
    return text[start_at: end_at if end_at > 0 else start_at + 1800]


def _sentences(text: str) -> list[str]:
    flattened = re.sub(r"\s+", " ", text).strip()
    if not flattened:
        return []
    parts = re.split(r"(?<=[.!?])\s+(?=[А-ЯA-Z«\"])", flattened)
    return [part.strip() for part in parts if len(part.strip()) >= 25]


def _exact_substring(page_text: str, sentence: str) -> Optional[str]:
    tokens = sentence.split()
    if len(tokens) < 2:
        return None
    pattern = r"\s+".join(re.escape(token) for token in tokens[:50])
    match = re.search(pattern, page_text, flags=re.IGNORECASE)
    if match is None:
        return None
    return match.group(0).strip()


def _is_marker(sentence: str) -> bool:
    lowered = sentence.lower().strip(" :.")
    return lowered in {"установил", "установила", "определил", "решил", "постановил"}


def _days_near(text: str, default: int) -> int:
    match = re.search(r"(\d+)\s+(?:рабочих\s+|календарных\s+)?дн", text, re.IGNORECASE)
    if match:
        return int(match.group(1))
    lowered = text.lower().replace("ё", "е")
    for word, value in _WORD_DAYS.items():
        if re.search(rf"\b{word.replace('ё', 'е')}\b", lowered):
            return value
    return default


def _shift_date(document_date: Optional[str], days: int) -> Optional[str]:
    if not document_date:
        return None
    for fmt in ("%d.%m.%Y", "%Y-%m-%d"):
        try:
            parsed = datetime.strptime(document_date, fmt).date()
        except ValueError:
            continue
        return (parsed + timedelta(days=days)).isoformat()
    return None


def _prompt_text(pages: list[PageText]) -> str:
    """Шапка и резолюция сохраняются, даже если середина документа не помещается."""

    pieces = [_clip_page(page) for page in pages]
    total = sum(len(piece) for piece in pieces)
    if len(pages) <= 15 and total <= 100_000:
        return "\n\n".join(pieces)
    tail_count = min(3, len(pages))
    tail = pieces[-tail_count:]
    head: list[str] = []
    used = sum(len(piece) for piece in tail)
    source = pieces[:-tail_count] if tail_count else pieces
    omitted = False
    for piece in source:
        if used + len(piece) > 100_000:
            omitted = True
            break
        head.append(piece)
        used += len(piece)
    if omitted:
        head.append("…[средние страницы опущены; резолютивная часть сохранена в последних страницах]")
    return "\n\n".join(head + tail)


def _clip_page(page: PageText) -> str:
    body = page.text.strip() or "[пустая страница или скан без текстового слоя]"
    if len(body) > 8000:
        body = body[:8000] + "\n…[страница обрезана]"
    return f"[PAGE {page.page}]\n{body}"


def _load_json(content: str) -> dict:
    cleaned = content.strip()
    if cleaned.startswith("```"):
        cleaned = re.sub(r"^```(?:json)?\s*", "", cleaned)
        cleaned = re.sub(r"\s*```$", "", cleaned)
    try:
        payload = json.loads(cleaned)
    except json.JSONDecodeError:
        match = re.search(r"\{.*\}", cleaned, flags=re.DOTALL)
        if match is None:
            raise ValueError("Ответ модели не содержит JSON") from None
        payload = json.loads(match.group(0))
    if not isinstance(payload, dict):
        raise ValueError("JSON модели должен быть объектом")
    return payload


def _unwrap_payload(payload: dict) -> dict:
    if "case_number" in payload:
        return payload
    for key in ("result", "analysis", "data", "document"):
        nested = payload.get(key)
        if isinstance(nested, dict):
            return nested
    return payload


def _coerce_document_type(value: str) -> DocumentType:
    if value in _DOCUMENT_TYPES:
        return value  # type: ignore[return-value]
    lowered = value.lower()
    for label in _DOCUMENT_TYPES:
        if label.lower() in lowered:
            return label  # type: ignore[return-value]
    raise ValueError(f"Неизвестный тип акта: {value}")


def _verify_quotes(pages: list[PageText], analysis: DocumentAnalysisResult) -> list[str]:
    warnings: list[str] = []
    references = list(analysis.key_points)
    references.extend(item.source_quote for item in analysis.deadlines)
    references.extend(item.source_quote for item in analysis.court_orders)
    if analysis.next_hearing and analysis.next_hearing.source_quote:
        references.append(analysis.next_hearing.source_quote)
    for reference in references:
        if _quote_matches(pages, reference.page_number, reference.exact_quote):
            reference.verified = True
            continue
        relocated = _find_page(pages, reference.exact_quote)
        if relocated is not None:
            reference.page_number = relocated
            reference.verified = True
            continue
        reference.verified = False
        warnings.append(
            "Цитата не найдена дословно в тексте PDF: "
            f"«{reference.exact_quote[:120]}»"
        )
    return warnings


def _read_token_usage(completion: object) -> Optional[dict[str, int]]:
    usage = getattr(completion, "usage", None)
    if usage is None:
        return None
    if isinstance(usage, dict):
        prompt = usage.get("prompt_tokens")
        completion_tokens = usage.get("completion_tokens")
        total = usage.get("total_tokens")
    else:
        prompt = getattr(usage, "prompt_tokens", None)
        completion_tokens = getattr(usage, "completion_tokens", None)
        total = getattr(usage, "total_tokens", None)
    if prompt is None and completion_tokens is None and total is None:
        return None
    counted = {
        "prompt_tokens": int(prompt or 0),
        "completion_tokens": int(completion_tokens or 0),
        "total_tokens": int(total or (int(prompt or 0) + int(completion_tokens or 0))),
    }
    logger.info(
        "LLM tokens: prompt=%s completion=%s total=%s",
        counted["prompt_tokens"],
        counted["completion_tokens"],
        counted["total_tokens"],
    )
    return counted


def _quote_matches(pages: list[PageText], page_number: int, quote: str) -> bool:
    page = next((item for item in pages if item.page == page_number), None)
    if page is not None and _norm(quote) in _norm(page.text):
        return True
    return _quote_on_page_seam(pages, quote, page_number)


def _quote_on_page_seam(pages: list[PageText], quote: str, page_number: Optional[int] = None) -> bool:
    normalized = _norm(quote)
    if len(normalized) < 12:
        return False
    ordered = sorted(pages, key=lambda item: item.page)
    for index in range(len(ordered) - 1):
        left = ordered[index]
        right = ordered[index + 1]
        if page_number is not None and page_number not in {left.page, right.page}:
            continue
        if normalized in _norm(f"{left.text} {right.text}"):
            return True
    return False


def _find_page(pages: list[PageText], quote: str) -> Optional[int]:
    normalized = _norm(quote)
    if len(normalized) < 12:
        return None
    for page in pages:
        if normalized in _norm(page.text):
            return page.page
    ordered = sorted(pages, key=lambda item: item.page)
    for index in range(len(ordered) - 1):
        if normalized in _norm(f"{ordered[index].text} {ordered[index + 1].text}"):
            return ordered[index].page
    return None


def _readable(value: str) -> str:
    cleaned = value.translate(
        str.maketrans(
            {
                "\u00ad": "-",
                "\u2010": "-",
                "\u2011": "-",
                "\u2012": "-",
                "\u2013": "-",
                "\u2014": "-",
                "\u2212": "-",
                "\u00a0": " ",
                "\u202f": " ",
            }
        )
    )
    return " ".join(cleaned.split())


def _without_marker(page_text: str, quote: str) -> str:
    stripped = re.sub(
        r"^(?:установил[аи]?|определил|решил|постановил)\s*:\s*",
        "",
        quote,
        count=1,
        flags=re.IGNORECASE,
    ).strip()
    if stripped and stripped in page_text:
        return stripped
    return quote.strip()


def _norm(value: str) -> str:
    compact = ocr_search_copy(value).replace("ё", "е").replace("Ё", "Е")
    compact = compact.translate(
        str.maketrans(
            {
                "\u00ad": "",
                "\u2010": "-",
                "\u2011": "-",
                "\u2013": "-",
                "\u2014": "-",
                "\u00a0": " ",
            }
        )
    )
    compact = re.sub(r"\s+", " ", compact)
    compact = re.sub(r"[^\w\s]", "", compact, flags=re.UNICODE)
    return compact.strip().lower()


def _response_format_rejected(exc: Exception) -> bool:
    text = str(exc).lower()
    markers = ("response_format", "json_object", "not supported", "unsupported", "400")
    return any(marker in text for marker in markers)


def apply_layer3(parsed: PdfParseResult, analysis: DocumentAnalysisResult) -> list[str]:
    """Проверяет цитаты, пересчитывает даты и подставляет справку из базы норм."""

    _drop_noise(analysis)
    _drop_duplicate_deadlines(analysis)
    warnings = _verify_quotes(parsed.pages, analysis)
    _merge_regex_facts(parsed, analysis)
    _dedupe_parties(analysis)
    warnings.extend(_drop_unseen_parties(parsed, analysis))
    _ensure_stage(analysis, "\n".join(page.text for page in parsed.pages))
    _dedupe_legal_basis(analysis)
    _recalculate_due_dates(analysis)
    analysis.legal_knowledge = _KNOWLEDGE.build(analysis.stage_code, analysis.legal_basis)
    return warnings


def _sanitize_llm_payload(
    payload: dict,
    parsed: PdfParseResult,
    fallback: DocumentAnalysisResult,
) -> dict:
    """Приводит сырой JSON модели к полям, которые принимает DocumentAnalysisResult."""

    del parsed
    warnings: list[str] = []
    stage = _match_stage(payload.get("stage_code"))
    if stage is None:
        stage = fallback.stage_code
        case_stage = _filled_text(payload.get("case_stage"), fallback.case_stage)
    else:
        case_stage = _filled_text(payload.get("case_stage"), STAGE_TITLES[stage])
    return {
        "case_number": _canonical_or_fallback(
            payload.get("case_number"),
            fallback.case_number,
        ),
        "court_name": _filled_text(payload.get("court_name"), fallback.court_name),
        "judge_name": _optional_str(payload.get("judge_name")) or fallback.judge_name,
        "document_type": _coerce_document_type_soft(payload.get("document_type"), fallback.document_type),
        "document_date": _optional_str(payload.get("document_date")) or fallback.document_date,
        "stage_code": stage,
        "case_stage": case_stage,
        "act_date": _iso_or_none(payload.get("act_date")) or _iso_or_none(fallback.act_date),
        "parties": _clean_parties(payload.get("parties"), warnings),
        "verdict_summary": _filled_text(payload.get("verdict_summary"), fallback.verdict_summary),
        "financial_claims": _string_list(payload.get("financial_claims")),
        "next_hearing": _clean_hearing(payload.get("next_hearing")),
        "court_orders": _clean_orders(payload.get("court_orders"), warnings),
        "deadlines": _clean_deadlines(payload.get("deadlines"), warnings),
        "legal_basis": _string_list(payload.get("legal_basis")),
        "key_points": _clean_key_points(payload.get("key_points"), warnings),
        "legal_knowledge": None,
        "_sanitize_warnings": warnings,
    }


def _as_list(value: object) -> list[object]:
    if not isinstance(value, list):
        return []
    return [item for item in value if item is not None]


def _string_list(value: object) -> list[str]:
    result: list[str] = []
    for item in _as_list(value):
        if isinstance(item, str) and item.strip():
            result.append(item.strip())
    return result


def _canonical_or_fallback(value: object, fallback: str) -> str:
    chosen = _filled_text(value, fallback)
    if not chosen or chosen == "НЕ ИЗВЛЕЧЁН" or "<" in chosen:
        return chosen
    return canonical_case_number(chosen)


def _filled_text(value: object, fallback: str) -> str:
    if isinstance(value, str) and value.strip():
        return value.strip()
    return fallback


def _optional_str(value: object) -> Optional[str]:
    if isinstance(value, str):
        text = value.strip()
        return text or None
    if isinstance(value, bool) or value is None:
        return None
    if isinstance(value, (int, float)):
        return str(value)
    return None


def _clean_parties(value: object, warnings: list[str]) -> list[dict[str, object]]:
    cleaned: list[dict[str, object]] = []
    for item in _as_list(value):
        if not isinstance(item, dict):
            warnings.append("Отброшен участник: элемент не является объектом")
            continue
        name = item.get("name")
        if not isinstance(name, str) or not name.strip():
            warnings.append("Отброшен участник: нет имени")
            continue
        party = {
            "role": _coerce_role(str(item.get("role") or "")),
            "name": name.strip(),
            "inn": _optional_str(item.get("inn")),
            "ogrn": _optional_str(item.get("ogrn")),
            "snils": _optional_str(item.get("snils")),
            "address": _optional_str(item.get("address")),
        }
        _keep_model(party, PartyInfo, cleaned, warnings, "участник")
    return cleaned


def _clean_key_points(value: object, warnings: list[str]) -> list[dict[str, object]]:
    cleaned: list[dict[str, object]] = []
    for item in _as_list(value):
        quote = _clean_quote(item, None)
        if quote is None:
            warnings.append("Отброшен key_point: пустая цитата")
            continue
        _keep_model(quote, QuoteReference, cleaned, warnings, "key_point")
    return cleaned


def _clean_deadlines(value: object, warnings: list[str]) -> list[dict[str, object]]:
    cleaned: list[dict[str, object]] = []
    for item in _as_list(value):
        if not isinstance(item, dict):
            warnings.append("Отброшен срок: элемент не является объектом")
            continue
        description = _optional_str(item.get("description")) or _optional_str(item.get("deadline_text"))
        days = _parse_days_limit(item.get("days_limit"))
        months = _parse_days_limit(item.get("months_limit"))
        if days is None:
            days = 0
        quote = _clean_quote(item.get("source_quote"), description)
        if description is None or quote is None:
            warnings.append("Отброшен срок: нет описания или цитаты")
            continue
        data = {
            "description": description,
            "due_date": _iso_or_none(item.get("due_date")),
            "days_limit": days,
            "months_limit": months,
            "days_type": _coerce_days_type(item.get("days_type")),
            "anchor_event": _coerce_anchor(item.get("anchor_event")),
            "urgency": _coerce_urgency(item.get("urgency"), days, months),
            "source_quote": quote,
        }
        _keep_model(data, DeadlineItem, cleaned, warnings, "срок")
    return cleaned


def _clean_orders(value: object, warnings: list[str]) -> list[dict[str, object]]:
    cleaned: list[dict[str, object]] = []
    for item in _as_list(value):
        if not isinstance(item, dict):
            warnings.append("Отброшено поручение суда: элемент не является объектом")
            continue
        action = _optional_str(item.get("action"))
        quote = _clean_quote(item.get("source_quote"), action or _optional_str(item.get("deadline_text")))
        if action is None or quote is None:
            warnings.append("Отброшено поручение суда: нет действия или цитаты")
            continue
        days = _parse_days_limit(item.get("days_limit"))
        actor = _optional_str(item.get("actor")) or "Лица участвующие в деле"
        if actor.lower() in {"не указан", "неизвестно", "none", "null"}:
            actor = "Лица участвующие в деле"
        data = {
            "actor": actor,
            "action": action,
            "deadline_text": _optional_str(item.get("deadline_text")),
            "days_limit": days,
            "months_limit": _parse_days_limit(item.get("months_limit")),
            "days_type": _coerce_days_type(item.get("days_type")),
            "anchor_event": _coerce_anchor(item.get("anchor_event")),
            "due_date": _iso_or_none(item.get("due_date")),
            "source_quote": quote,
        }
        _keep_model(data, CourtOrderItem, cleaned, warnings, "поручение суда")
    return cleaned


def _clean_quote(value: object, backup: Optional[str]) -> Optional[dict[str, object]]:
    exact: object = None
    page_raw: object = 1
    if isinstance(value, str):
        exact = value
    elif isinstance(value, dict):
        exact = value.get("exact_quote")
        if exact is None:
            exact = value.get("quote")
        page_raw = value.get("page_number")
    text = exact.strip() if isinstance(exact, str) else ""
    if not text:
        text = backup.strip() if isinstance(backup, str) else ""
    if not text:
        return None
    return {"page_number": _page_number(page_raw), "exact_quote": text[:2000], "verified": True}


def _page_number(value: object) -> int:
    if isinstance(value, bool) or value is None:
        return 1
    if isinstance(value, int):
        return value if value >= 1 else 1
    if isinstance(value, float):
        number = int(value)
        return number if number >= 1 else 1
    if isinstance(value, str):
        match = re.search(r"\d+", value)
        if match:
            number = int(match.group(0))
            return number if number >= 1 else 1
    return 1


def _clean_hearing(value: object) -> Optional[dict[str, object]]:
    if not isinstance(value, dict) or not value:
        return None
    date_value = _iso_or_none(value.get("date"))
    time_value = _optional_str(value.get("time"))
    location = _optional_str(value.get("location"))
    purpose = _optional_str(value.get("purpose"))
    quote = _clean_quote(value.get("source_quote"), None)
    if date_value is None and time_value is None and location is None and purpose is None and quote is None:
        return None
    hearing = NextHearingInfo(
        date=date_value,
        time=time_value,
        location=location,
        purpose=purpose,
        source_quote=QuoteReference.model_validate(quote) if quote else None,
    )
    return hearing.model_dump()


def _keep_model(
    data: dict[str, object],
    model: type[PartyInfo] | type[QuoteReference] | type[DeadlineItem] | type[CourtOrderItem],
    sink: list[dict[str, object]],
    warnings: list[str],
    label: str,
) -> None:
    try:
        sink.append(model.model_validate(data).model_dump())
    except ValidationError as exc:
        warnings.append(f"Отброшен {label}: {_validation_field_list(exc)}")


def _match_stage(value: object) -> Optional[StageCode]:
    if not isinstance(value, str) or not value.strip():
        return None
    token = value.strip()
    if token in _STAGE_CODES:
        return token  # type: ignore[return-value]
    lowered = token.lower().replace(" ", "_").replace("-", "_")
    if lowered in _STAGE_CODES:
        return lowered  # type: ignore[return-value]
    for code, title in STAGE_TITLES.items():
        if title.lower() in token.lower() or code in lowered:
            return code
    markers = (
        "субсидиар",
        "оспариван",
        "реестр",
        "реструктуризац",
        "реализац",
        "наблюден",
        "конкурсн",
        "банкрот",
        "61.2",
        "61.3",
    )
    if any(marker in token.lower() for marker in markers):
        return _classify_stage(token)[0]
    return None


def _coerce_document_type_soft(value: object, fallback: DocumentType) -> DocumentType:
    if not isinstance(value, str) or not value.strip():
        return fallback
    try:
        return _coerce_document_type(value)
    except ValueError:
        return fallback


def _parse_days_limit(value: object) -> Optional[int]:
    if isinstance(value, bool) or value is None:
        return None
    if isinstance(value, int):
        return value if value >= 0 else None
    if isinstance(value, float):
        return int(value) if value >= 0 else None
    if isinstance(value, str):
        match = re.search(r"\d+", value)
        if match:
            return int(match.group(0))
        lowered = value.lower().replace("ё", "е")
        for word, number in _WORD_DAYS.items():
            if re.search(rf"\b{word}\b", lowered):
                return number
    return None


def _coerce_days_type(value: object) -> str:
    if isinstance(value, str):
        lowered = value.lower()
        if lowered in {"calendar", "business", "unknown"}:
            return lowered
        if "рабоч" in lowered:
            return "business"
        if "календар" in lowered:
            return "calendar"
        if "неизв" in lowered or "unknown" in lowered:
            return "unknown"
    return "calendar"


def _coerce_anchor(value: object) -> str:
    if isinstance(value, str):
        lowered = value.lower()
        if lowered in {"act_date", "receipt_date", "hearing_date", "unknown"}:
            return lowered
        if "получен" in lowered or "receipt" in lowered:
            return "receipt_date"
        if "заседан" in lowered or "hearing" in lowered:
            return "hearing_date"
        if "fixed" in lowered or "прям" in lowered or "конечн" in lowered:
            return "fixed_date"
        if "акт" in lowered or "вынес" in lowered:
            return "act_date"
        if lowered.strip():
            return "unknown"
    return "act_date"


def _coerce_urgency(value: object, days: int, months: Optional[int] = None) -> str:
    if isinstance(months, int) and months >= 1:
        return "normal"
    if days > 10:
        return "normal"
    if 1 <= days <= 10:
        return "critical"
    if isinstance(value, str) and value.strip().lower() == "critical" and days == 0:
        return "critical"
    return "normal"


def _public_llm_text(text: str) -> str:
    redacted = re.sub(r"sk-[A-Za-z0-9_\-]+", "[key]", text)
    redacted = re.sub(r"AQVN[A-Za-z0-9_\-]+", "[key]", redacted)
    return redacted[:1500]


def _validation_field_list(exc: ValidationError) -> str:
    parts = [f"{'.'.join(str(item) for item in err['loc'])}: {err['type']}" for err in exc.errors()]
    return "; ".join(parts)[:1500]


def _coerce_role(value: str) -> PartyRole:
    if value in _ROLES:
        return value  # type: ignore[return-value]
    lowered = value.lower().replace("ё", "е")
    if "саморегулир" in lowered or re.search(r"(^|[^а-яёa-z])сро([^а-яёa-z]|$)", lowered):
        return "СРО АУ"
    if lowered in {"ау", "а/у", "фу"} or "управля" in lowered:
        return "Финансовый управляющий"
    if "кред" in lowered:
        return "Кредитор"
    if "ответ" in lowered:
        return "Ответчик"
    if "ист" in lowered:
        return "Истец"
    if "заявит" in lowered or "долж" in lowered or "граждан" in lowered:
        return "Должник"
    return "Третье лицо"


def _classify_stage(text: str) -> tuple[StageCode, str]:
    lowered = re.sub(r"\s+", " ", text.lower().replace("ё", "е"))
    if "субсидиар" in lowered:
        code: StageCode = "subsidiary_liability"
    elif ("оспариван" in lowered and "сдел" in lowered) or "61.2" in lowered or "61.3" in lowered:
        code = "transaction_challenge"
    elif "реестр требований" in lowered or "включить требование" in lowered:
        code = "creditor_registry_claim"
    elif "реструктуризац" in lowered and "долг" in lowered:
        code = "bankruptcy_individual_restructuring"
    elif ("реализац" in lowered and "имуществ" in lowered) or "признать банкротом" in lowered or "признан банкротом" in lowered:
        code = "bankruptcy_individual_realization"
    elif any(token in lowered for token in ("наблюден", "конкурсн", "внешн управлен")):
        code = "bankruptcy_legal_entity"
    elif "банкрот" in lowered and any(token in lowered for token in ("гражданин", "физическ", "должник")):
        if any(token in lowered for token in ("ооо", "ао ", "пао", "юридическ")):
            code = "bankruptcy_legal_entity"
        elif "принять заявление" in lowered or "принят" in lowered or "без движения" in lowered:
            code = "bankruptcy_individual_accept"
        else:
            code = "bankruptcy_individual_realization"
    else:
        code = "general_arbitration_dispute"
    return code, STAGE_TITLES[code]


def _ensure_stage(analysis: DocumentAnalysisResult, text: str) -> None:
    if analysis.stage_code == "bankruptcy_individual_intro" or analysis.stage_code not in _STAGE_CODES:
        analysis.stage_code, _title = _classify_stage(text)
        if analysis.stage_code == "general_arbitration_dispute" and "банкрот" in text.lower():
            analysis.stage_code = "bankruptcy_individual_realization"
    elif analysis.stage_code == "general_arbitration_dispute":
        code, _title = _classify_stage(text)
        if code != "general_arbitration_dispute":
            analysis.stage_code = code
    analysis.case_stage = STAGE_TITLES[analysis.stage_code]


def _merge_regex_facts(parsed: PdfParseResult, analysis: DocumentAnalysisResult) -> None:
    metadata = parsed.metadata
    full_text = "\n".join(page.text for page in parsed.pages)
    normalized = _norm(full_text)
    if metadata.case_number and (
        analysis.case_number in {"", "НЕ ИЗВЛЕЧЁН"}
        or "<" in analysis.case_number
        or _norm(analysis.case_number) not in normalized
    ):
        analysis.case_number = metadata.case_number
    if analysis.case_number and "<" not in analysis.case_number and analysis.case_number != "НЕ ИЗВЛЕЧЁН":
        analysis.case_number = canonical_case_number(analysis.case_number)
    if metadata.act_date and not analysis.act_date:
        analysis.act_date = metadata.act_date
    if metadata.court_name and (
        analysis.court_name in {"", "Суд не указан в текстовом слое"}
        or "<" in analysis.court_name
        or _norm(analysis.court_name) not in normalized
    ):
        analysis.court_name = metadata.court_name
    if metadata.judge_name and not analysis.judge_name:
        analysis.judge_name = metadata.judge_name
    for party in metadata.parties:
        if any(_same_party(party.name, existing.name) for existing in analysis.parties):
            continue
        if _party_seen(party.name, normalized):
            analysis.parties.append(party)
    _attach_nearby_ids(full_text, analysis, metadata.inns, metadata.snils_list)
    for name in metadata.sro_names:
        if any(name in party.name for party in analysis.parties):
            continue
        analysis.parties.append(PartyInfo(role="СРО АУ", name=name))


def _drop_unseen_parties(parsed: PdfParseResult, analysis: DocumentAnalysisResult) -> list[str]:
    """Убирает стороны, которых нет в тексте: модель иногда копирует их из примера JSON."""

    normalized = _norm("\n".join(page.text for page in parsed.pages))
    kept: list[PartyInfo] = []
    warnings: list[str] = []
    for party in analysis.parties:
        if _party_seen(party.name, normalized):
            kept.append(party)
            continue
        warnings.append(f"Участник отброшен: имя не найдено в тексте PDF: {party.name}")
    analysis.parties = kept
    return warnings


def _same_party(left: str, right: str) -> bool:
    stems_left = _name_stems(left)
    stems_right = _name_stems(right)
    if not stems_left or not stems_right:
        return _norm(left) == _norm(right) and bool(_norm(left))
    return any(stem_matches(left_stem, right_stem) for left_stem in stems_left for right_stem in stems_right)


def _name_stems(name: str) -> list[str]:
    stems: list[str] = []
    for token in _norm(name).split():
        if token in {"ооо", "ао", "пао", "зао", "ип"}:
            continue
        if len(token) >= 5:
            stems.append(token[:-2])
        elif len(token) >= 4:
            stems.append(token)
    return stems


def stem_matches(left: str, right: str) -> bool:
    if len(left) < 4 or len(right) < 4:
        return False
    return left == right or left.startswith(right) or right.startswith(left)

_NOISE_MARKERS = (

    "до подачи заявления",

def _is_organization(party: PartyInfo) -> bool:
    if party.role == "СРО АУ":
        return True
    lowered = f" {_norm(party.name)} "
    return any(mark in lowered for mark in (" ооо ", " ао ", " пао ", " зао ", " ассоциац", " саморегулир"))


def _id_near_name(lowered: str, name: str, identifier: str) -> bool:
    needles = _name_stems(name) or ([_norm(name)] if _norm(name) else [])
    for needle in needles:
        if len(needle) < 4:
            continue
        start = 0
        while True:
            index = lowered.find(needle, start)
            if index < 0:
                break
            window = lowered[max(0, index - 200): index + len(needle) + 200]
            if identifier in window.replace(" ", ""):
                return True
            start = index + len(needle)
    return False


def _attach_nearby_ids(
    text: str,
    analysis: DocumentAnalysisResult,
    inns: list[str],
    snils_list: list[str],
) -> None:
    lowered = ocr_search_copy(text).lower().replace("ё", "е")
    for party in analysis.parties:
        for inn in inns:
            if party.inn:
                break
            if len(inn) == 12 and (party.role == "СРО АУ" or _is_organization(party)):
                continue
            if _id_near_name(lowered, party.name, inn):
                party.inn = inn
        for snils in snils_list:
            if party.snils or party.role == "СРО АУ" or _is_organization(party):
                break
            if _id_near_name(lowered, party.name, snils):
                party.snils = snils
    individuals = [
        party for party in analysis.parties
        if party.role == "Должник" and not _is_organization(party) and not party.inn
    ]
    personal = [inn for inn in inns if len(inn) == 12]
    if len(individuals) == 1 and len(personal) == 1:
        individuals[0].inn = personal[0]


def _dedupe_parties(analysis: DocumentAnalysisResult) -> None:
    kept: list[PartyInfo] = []
    for party in analysis.parties:
        match = next((item for item in kept if _same_party(item.name, party.name)), None)
        if match is None:
            kept.append(party)
            continue
        winner = party if _ROLE_RANK.get(party.role, 0) > _ROLE_RANK.get(match.role, 0) else match
        donor = match if winner is party else party
        winner.inn = winner.inn or donor.inn
        winner.snils = winner.snils or donor.snils
        winner.ogrn = winner.ogrn or donor.ogrn
        winner.address = winner.address or donor.address

    analysis.parties = kept


def _drop_duplicate_deadlines(analysis: DocumentAnalysisResult) -> None:

def _same_order_and_deadline(deadline: DeadlineItem, order: CourtOrderItem) -> bool:
    quote = _norm(deadline.source_quote.exact_quote)
    order_quote = _norm(order.source_quote.exact_quote)
    if quote and quote == order_quote:
        return True
    if deadline.anchor_event != order.anchor_event:
        return False
    if (deadline.days_limit or 0) != (order.days_limit or 0):
        return False
    if (deadline.months_limit or 0) != (order.months_limit or 0):
        return False
    if not (deadline.days_limit or deadline.months_limit or deadline.anchor_event == "fixed_date"):
        return False
    return _task_substance_matches(deadline.description, order.action)


def _task_substance_matches(description: str, action: str) -> bool:
    left = _norm(description)
    right = _norm(action)
    if not left or not right:
        return False
    if left in right or right in left:
        return True
    stems = [token[:-2] for token in left.split() if len(token) >= 6]
    return any(len(stem) >= 5 and stem in right for stem in stems)

        if "kad.arbitr" in quote:

def _party_seen(name: str, normalized_text: str) -> bool:
    normalized = _norm(name)
    if len(normalized) >= 4 and normalized in normalized_text:
        return True
    stop = {
        "ооо",

        "пао",
        "ао",
        "ип",
        "зао",
        "общество",
        "ограниченной",
        "ответственностью",
        "акционерное",
    }
    tokens = [token for token in normalized.split() if len(token) >= 4 and token not in stop]

def _align_days_type(item: DeadlineItem | CourtOrderItem) -> None:

    if "рабоч" in quote:

def calculate_due_date(
    start_iso: str,
    days_limit: int,
    days_type: str,
    months_limit: int = 0,
) -> Optional[str]:
    """Считает срок от даты. Конец в выходной переносится на понедельник, ч. 4 ст. 114 АПК РФ."""

    start = _parse_date(start_iso)
    if start is None:
        return None
    if months_limit > 0:
        result = _add_months(start, months_limit)
        return _shift_weekend(result).isoformat()
    if days_limit < 0 or days_type == "unknown":
        return None
    if days_type == "business":
        return _add_business_days(start, days_limit).isoformat()
    return _shift_weekend(start + timedelta(days=days_limit)).isoformat()


def _add_months(start: date, months: int) -> date:
    month_index = start.month - 1 + months
    year = start.year + month_index // 12
    month = month_index % 12 + 1
    day = min(start.day, monthrange(year, month)[1])
    return date(year, month, day)


def _shift_weekend(value: date) -> date:
    if value.weekday() == 5:
        return value + timedelta(days=2)
    if value.weekday() == 6:
        return value + timedelta(days=1)
    return value


def _apply_due_date(item: DeadlineItem | CourtOrderItem, anchor: Optional[str]) -> None:
    if item.anchor_event == "fixed_date" and item.due_date:
        item.due_date = _to_iso_date(item.due_date) or item.due_date
        return
    if item.anchor_event == "receipt_date":
        item.due_date = None
        return
    if item.anchor_event != "act_date" or not anchor:
        if item.anchor_event != "fixed_date":
            return
        item.due_date = None
        return
    months = item.months_limit or 0
    if months > 0:
        item.due_date = calculate_due_date(anchor, 0, "calendar", months)
        return
    if item.days_limit is None or item.days_type == "unknown":
        item.due_date = None
        return
    item.due_date = calculate_due_date(anchor, item.days_limit, item.days_type)


def _add_business_days(start: date, days: int) -> date:
    current = start
    left = days
    while left > 0:
        current += timedelta(days=1)
        if current.weekday() < 5:
            left -= 1
    return current


def _next_hearing(pages: list[PageText]) -> Optional[NextHearingInfo]:
    for page in pages:
        for sentence in _sentences(page.text):
            if not re.search(r"заседани", sentence, re.IGNORECASE):
                continue
            date_match = re.search(r"\b(\d{2}\.\d{2}\.\d{4})\b", sentence)
            textual = re.search(
                r"\b(\d{1,2})\s+(января|февраля|марта|апреля|мая|июня|июля|августа|сентября|октября|ноября|декабря)\s+(\d{4})",
                sentence,
                re.IGNORECASE,
            )
            if date_match is None and textual is None:
                continue
            quote = _exact_substring(page.text, sentence)
            if quote is None:
                continue
            time_match = re.search(r"\b(\d{1,2}:\d{2})\b", sentence)
            room_match = re.search(r"((?:зал|кабинет)\w*\s*№?\s*\d+)", sentence, re.IGNORECASE)
            if date_match:
                hearing_date = _to_iso_date(date_match.group(1))
            else:
                assert textual is not None
                hearing_date = _to_iso_date(
                    f"{int(textual.group(1)):02d}.{_month_number(textual.group(2))}.{textual.group(3)}"
                )
            return NextHearingInfo(
                date=hearing_date,
                time=time_match.group(1) if time_match else None,
                location=room_match.group(1) if room_match else None,
                purpose="Судебное заседание",
                source_quote=QuoteReference(page_number=page.page, exact_quote=quote[:700]),
            )
    return None


def _court_orders(pages: list[PageText]) -> list[CourtOrderItem]:
    orders: list[CourtOrderItem] = []
    for page in pages:
        section = _between(page.text, ("определил", "решил", "постановил"), ("судья",))
        parts = re.split(r"(?:^|\n)\s*\d+[\.\)]\s+", section)
        if len(parts) <= 1:
            continue
        for part in parts[1:]:
            sentences = _sentences(part)
            sentence = sentences[0] if sentences else " ".join(part.split())
            if len(sentence) < 20:

            quote = _exact_substring(page.text, sentence[:350])
            if quote is None:
                continue
            has_days = _has_day_phrase(sentence)

            orders.append(
                CourtOrderItem(
                    actor=_actor(sentence),
                    action=sentence[:500],
                    deadline_text=sentence[:300] if has_days else None,
                    days_limit=_days_near(sentence, 0) if has_days else None,
                    days_type="business" if "рабоч" in sentence.lower() else "calendar",
                    anchor_event="receipt_date" if receipt else "act_date",
                    source_quote=QuoteReference(page_number=page.page, exact_quote=quote[:700]),
                )
            )
            if len(orders) >= 8:
                return orders
    return orders

def _parse_date(value: Optional[str]) -> Optional[date]:
    if not value:
        return None
    text = " ".join(value.replace("ё", "е").split())
    for fmt in ("%Y-%m-%d", "%d.%m.%Y"):
        try:
            return datetime.strptime(text, fmt).date()
        except ValueError:
            continue
    iso = re.search(r"\b(\d{4})-(\d{2})-(\d{2})\b", text)
    if iso:
        return _safe_date(int(iso.group(1)), int(iso.group(2)), int(iso.group(3)))
    dotted = re.search(r"\b(\d{2})\.(\d{2})\.(\d{4})\b", text)
    if dotted:
        return _safe_date(int(dotted.group(3)), int(dotted.group(2)), int(dotted.group(1)))

    if textual is None:
        return None
    month = _MONTH_INDEX.get(textual.group(2).lower().replace("ё", "е"))
    if month is None:
        return None
    return _safe_date(int(textual.group(3)), month, int(textual.group(1)))

def _consultant_query(article: str) -> str:

class LegalKnowledgeService:
    """Возвращает одну и ту же справку для одного и того же stage_code."""

    def build(self, stage_code: str, legal_basis: list[str]) -> LegalKnowledgeBlock:
        requested = "bankruptcy_individual_realization" if stage_code == "bankruptcy_individual_intro" else stage_code
        code: StageCode = requested if requested in _STAGE_CODES else "general_arbitration_dispute"  # type: ignore[assignment]
        base = _CARDS[code]
        articles = list(base.statutory_articles)
        known = {item.article for item in articles}
        for note in self._notes_for_basis(legal_basis):
            if note.article not in known:
                articles.append(note)
                known.add(note.article)
        return base.model_copy(update={"statutory_articles": articles})

    def _notes_for_basis(self, legal_basis: list[str]) -> list[StatutoryReference]:
        found: list[StatutoryReference] = []
        seen: set[tuple[str, str]] = set()
        for clause in legal_basis:
            for key in _keys_in_clause(clause):
                note = _ARTICLE_NOTES.get(key)
                if note is None or key in seen:
                    continue
                seen.add(key)
                found.append(note)
        return found


def _keys_in_clause(clause: str) -> list[tuple[str, str]]:
    lowered = clause.lower()
    if re.search(r"апк", lowered):
        family = "apk"
    elif re.search(r"гк\s*рф", lowered):
        family = "gk"
    elif re.search(r"127|банкрот|несостоятельн", lowered):
        family = "127"
    else:
        family = ""
    numbers = re.findall(
        r"(?:ст(?:ать(?:я|и|ями|ей|е|ю)|\.)\s*)(\d+(?:\.\d+)?)",
        clause,
        flags=re.IGNORECASE,
    )
    if not numbers:
        numbers = re.findall(r"\b(\d{2,3}(?:\.\d{1,2})?)\b", clause)
    keys: list[tuple[str, str]] = []
    for number in numbers:
        if family:
            keys.append((family, number))
        else:
            keys.append(("127", number))
            keys.append(("apk", number))
    return keys

def detect_court_system(case_number: str) -> CourtSystem:
    """А40-… — арбитраж (КАД), УИД или «~» — суд общей юрисдикции."""

    raw = case_number.strip()
    if "~" in raw or _UID_RE.search(raw):
        return "general_jurisdiction"
    if _ARB_RE.match(raw):
        return "arbitration"
    if _SOJ_RE.match(raw):
        return "general_jurisdiction"
    return "arbitration"


def _source_for(system: CourtSystem) -> CourtSource:
    if system == "arbitration":
        return "kad.arbitr.ru"
    return "sudrf.ru"


def _recognized(case_number: str) -> bool:
    raw = case_number.strip()
    return bool(_ARB_RE.match(raw) or "~" in raw or _UID_RE.search(raw) or _SOJ_RE.match(raw))


def _env_flag(name: str, default: bool) -> bool:
    raw = os.getenv(name)
    if raw is None or not raw.strip():
        return default
    return raw.strip().lower() in {"1", "true", "yes", "on"}

@asynccontextmanager
async def _chromium_page() -> AsyncIterator[object]:
    try:
        from playwright.async_api import async_playwright
    except ImportError as exc:
        raise CourtScraperError(
            "Пакет playwright не установлен. Выполните: pip install playwright && playwright install chromium"

            ) from exc
        try:
            page = await browser.new_page(locale="ru-RU", user_agent=_USER_AGENT)
            yield page
        finally:
            await browser.close()


async def _dismiss_overlays(page: Any) -> None:
    for label in ("Закрыть", "Понятно", "Нет, спасибо"):
        locator = page.get_by_text(label, exact=False)
        try:
            if await locator.count():
                await locator.first.click(timeout=1200)
        except Exception:
            continue


async def _fill_first(page: Any, selectors: tuple[str, ...], value: str) -> None:
    if not await _try_fill(page, selectors, value):
        raise CourtScraperError("На странице суда не найдено поле номера дела.")


async def _try_fill(page: Any, selectors: tuple[str, ...], value: str) -> bool:
    for selector in selectors:
        locator = page.locator(selector)
        try:
            if await locator.count():
                await locator.first.fill(value, timeout=4000)
                return True
        except Exception:
            continue
    return False


async def _click_first(page: Any, selectors: tuple[str, ...]) -> None:
    for selector in selectors:
        locator = page.locator(selector)
        try:
            if await locator.count():
                await locator.first.click(timeout=4000)
                return
        except Exception:
            continue
    await page.keyboard.press("Enter")

def _card_from_visible_text(
    case_number: str,
    text: str,
    *,
    source: CourtSource,
    system: CourtSystem,
) -> CaseCard:
    judge_match = re.search(
        r"(?:судья|судьи)\s+([А-ЯЁ][а-яё]+(?:\s+[А-ЯЁ]\.\s*[А-ЯЁ]\.|(?:\s+[А-ЯЁ][а-яё]+){1,2}))",
        text,
        re.IGNORECASE,
    )
    court_name = _visible_court_name(text) or (
        "Арбитражный суд" if system == "arbitration" else "Суд общей юрисдикции"
    )
    hearings: list[HearingEvent] = []
    acts: list[CourtAct] = []
    for line in text.splitlines():
        cleaned = " ".join(line.split())
        date_match = re.search(r"\b(\d{2}\.\d{2}\.\d{4})\b", cleaned)
        if date_match is None or len(cleaned) < 12:
            continue

        if "заседан" in lowered:
            hearings.append(
                HearingEvent(
                    date=_iso_date(date_match.group(1)),
                    instance=court_name,
                    result=cleaned[:240],
                    description=cleaned[:240],
                )
            )
        if any(word in lowered for word in ("определен", "решен", "постановлен")):
            acts.append(
                CourtAct(
                    date=_iso_date(date_match.group(1)),
                    document_type=_act_type(lowered),
                    instance=court_name,
                    title=cleaned[:300],
                )
            )
    return CaseCard(
        case_number=case_number.strip(),
        court_system=system,
        source=source,
        mode="live",
        court_name=court_name,
        instance=court_name,
        judge_name=judge_match.group(1).strip() if judge_match else None,
        case_status="Сведения со страницы суда",
        registered_at=hearings[0].date if hearings else None,
        hearings=hearings[:20],
        acts=acts[:20],

def _timeline(year: int, seed: int) -> list[date]:
    start = date(year, 2, 10) + timedelta(days=seed % 80)
    points = [start + timedelta(days=step) for step in (0, 21, 45, 78)]
    today = date.today()
    adjusted: list[date] = []
    for index, current in enumerate(points):
        if current > today:
            current = today - timedelta(days=(len(points) - index) * 14)
        adjusted.append(current)
    return adjusted

def _inn10(seed: int) -> str:
    body = f"{seed % 1_000_000_000:09d}"
    digits = [int(char) for char in body]
    checksum = sum(digit * coeff for digit, coeff in zip(digits, (2, 4, 10, 3, 5, 9, 4, 6, 8))) % 11 % 10
    return body + str(checksum)

    body = f"{seed % 10**12:012d}"
    checksum = int(body) % 11 % 10
    return body + str(checksum)

_TASK_KEY = re.compile(r"^doc:(\d+):(order|deadline):(\d+)$")


def _now() -> str:
    return datetime.now().isoformat(timespec="seconds")


def _stored_case_number(value: str) -> str:
    if not value or value == "НЕ ИЗВЛЕЧЁН":
        return value
    return canonical_case_number(value)


def _parse_iso(value: str) -> Optional[date]:
    try:
        return date.fromisoformat(value)
    except ValueError:
        return None


def _locate_task(
    documents: list[DocumentUploadItem],
    task_key: str,
) -> Optional[tuple[Optional[int], str]]:
    match = _TASK_KEY.match(task_key)
    if match is None:
        return None
    doc_id = int(match.group(1))
    index = int(match.group(3))
    document = next((item for item in documents if item.doc_id == doc_id), None)
    if document is None:
        return None
    items = document.analysis.court_orders if match.group(2) == "order" else document.analysis.deadlines
    if index < 0 or index >= len(items):
        return None
    found = items[index]
    return found.days_limit, found.days_type, found.months_limit or 0


def _task_counts(documents: list[DocumentUploadItem], states: dict[str, TaskStateItem]) -> tuple[int, int]:
    total = 0
    done = 0
    for document in documents:
        if _is_archived(document, documents):
            continue
        for kind, items in (
            ("order", document.analysis.court_orders),
            ("deadline", document.analysis.deadlines),
        ):
            for index, _item in enumerate(items):
                total += 1
                state = states.get(f"doc:{document.doc_id}:{kind}:{index}")
                if state is not None and state.is_done:
                    done += 1
    return done, total - done


def _metrics(
    documents: list[DocumentUploadItem],
    states: dict[str, TaskStateItem],
) -> tuple[Urgency, Optional[str], Optional[str]]:
    dues: list[str] = []
    hearings: list[str] = []
    urgent = False
    for document in documents:
        if _is_archived(document, documents):
            continue
        analysis = document.analysis
        if analysis.next_hearing and analysis.next_hearing.date:
            hearings.append(analysis.next_hearing.date)
        groups = (
            ("order", analysis.court_orders),
            ("deadline", analysis.deadlines),
        )
        for kind, items in groups:
            for index, item in enumerate(items):
                state = states.get(f"doc:{document.doc_id}:{kind}:{index}")
                if state is not None and state.is_done:
                    continue
                due = state.calculated_due_date if state is not None and state.calculated_due_date else item.due_date
                if due:
                    dues.append(due)
                if _open_task_is_urgent(item, due):
                    urgent = True
    nearest = min(dues) if dues else None
    hearing = min(hearings) if hearings else None
    if _within_days(nearest, 10) or _within_days(hearing, 3):
        urgent = True
    urgency: Urgency = "critical" if urgent else "normal"
    return urgency, nearest, hearing

    urgency, nearest, hearing = _metrics(documents, states)

    header: dict[str, object] = {
        "urgency": urgency,

    if newest is not None:

def _refresh_saved_analysis(analysis: DocumentAnalysisResult) -> None:
    """Старые карточки intro при показе становятся реализацией или реструктуризацией, справка берётся из кодекса."""

    summary = (analysis.verdict_summary or "").lower().replace("ё", "е")
    if analysis.stage_code == "bankruptcy_individual_intro":
        analysis.stage_code = (

            if "реструктуризац" in summary and "реализац" not in summary

        )
        analysis.case_stage = STAGE_TITLES[analysis.stage_code]

def _procedure_rank(analysis: DocumentAnalysisResult) -> int:
    blob = f"{analysis.stage_code} {analysis.case_stage} {analysis.verdict_summary}".lower().replace("ё", "е")
    if analysis.stage_code in {
        "bankruptcy_individual_restructuring",

        "bankruptcy_individual_intro",
    } or "реализац" in blob or "реструктуризац" in blob or "признан банкротом" in blob or "признать банкротом" in blob:

    if "без движения" in blob:
        return 0
    return 1


def _is_archived(document: DocumentUploadItem, documents: list[DocumentUploadItem]) -> bool:
    own_date = document.analysis.act_date or ""
    if not own_date:
        return False
    own_rank = _procedure_rank(document.analysis)
    for other in documents:
        other_date = other.analysis.act_date or ""
        if other is document or not other_date:
            continue
        if other_date > own_date and _procedure_rank(other.analysis) > own_rank:
            return True
    return False


def _open_task_is_urgent(item: object, due: Optional[str]) -> bool:
    months = getattr(item, "months_limit", None) or 0
    days_limit = getattr(item, "days_limit", None)
    if due:
        parsed = _parse_iso(due)
        if parsed is None:
            return False
        delta = (parsed - date.today()).days
        return -30 <= delta <= 10
    if isinstance(months, int) and months >= 1:
        return False
    if isinstance(days_limit, int) and days_limit > 10:
        return False
    return isinstance(days_limit, int) and 1 <= days_limit <= 10


def _urgency_from_analysis(analysis: DocumentAnalysisResult) -> str:
    if any(item.urgency == "critical" for item in analysis.deadlines):
        return "critical"
    nearest = _nearest_deadline(analysis)
    if _within_days(nearest, 10) or _within_days(
        analysis.next_hearing.date if analysis.next_hearing else None,
        3,
    ):
        return "critical"
    return "normal"


def _nearest_deadline(analysis: DocumentAnalysisResult) -> Optional[str]:
    dates = [item.due_date for item in analysis.deadlines if item.due_date]
    dates.extend(item.due_date for item in analysis.court_orders if item.due_date)
    return min(dates) if dates else None


def _within_days(value: Optional[str], limit: int) -> bool:
    if not value:
        return False
    try:
        target = date.fromisoformat(value)
    except ValueError:
        return False
    return 0 <= (target - date.today()).days <= limit


def _next_future_hearing(card: CaseCard) -> Optional[str]:
    today = date.today().isoformat()
    future = sorted(item.date for item in card.hearings if item.date >= today)
    if future:
        return future[0]
    return None


def _stage_from_card(card: CaseCard) -> tuple[str, str]:
    category = (card.category or "").lower()
    title = card.category or "Арбитражный спор"
    if "банкрот" in category:
        debtor_names = " ".join(party.name.lower() for party in card.parties if party.role == "Должник")
        if any(marker in debtor_names for marker in ("ооо", "ао ", "пао", "зао")):
            return "bankruptcy_legal_entity", title
        return "bankruptcy_individual_accept", title
    return "general_arbitration_dispute", title

    error.classList.remove("hidden");
    return;
  }
  const progress = document.getElementById("progress");
  const bar = document.getElementById("progress-bar");
  const list = document.getElementById("progress-steps");
  progress.classList.remove("hidden");
  list.innerHTML = steps.map((step, index) => `<li data-step="${index}">${step}</li>`).join("");
  let stepIndex = 0;
  bar.style.width = "15%";

    stepIndex = Math.min(stepIndex + 1, steps.length - 1);
    bar.style.width = `${20 + stepIndex * 30}%`;
    list.querySelectorAll("li").forEach((item, index) => {
      item.className = index <= stepIndex ? "font-medium text-navy" : "";
    });
  }, 700);
  try {
    const body = new FormData();
    files.forEach((file) => body.append("files", file));
    const response = await fetch("/api/documents/upload", { method: "POST", body });
    const payload = await response.json();

function caseBrief(documents, parties, claims, openCount, hearing) {
  const analysis = documents[0].analysis;
  const debtor = parties.find((party) => party.role === "Должник");
  const manager = parties.find((party) => party.role === "Финансовый управляющий");
  const judge = analysis.judge_name ? `, судья ${analysis.judge_name}` : "";
  let text = `Дело № ${analysis.case_number} (${analysis.court_name}${judge}):`;
  if (debtor) text += ` должник ${shortName(debtor.name)}`;
  text += ` — ${analysis.case_stage}.`;
  if (manager) text += ` Финансовый управляющий — ${shortName(manager.name).replace(/\.$/, "")}.`;
  if (analysis.verdict_summary) text += ` ${analysis.verdict_summary}`;
  if (claims.length) text += ` Суммы из актов: ${claims.slice(0, 2).join("; ")}.`;

function procedureRank(analysis) {

function isArchived(documentItem, documents) {
  const own = documentItem.analysis.act_date || "";
  if (!own) return false;

function uniqueParties(documents) {
  const parties = [];
  const rank = { "Финансовый управляющий": 4, "СРО АУ": 3, "Должник": 2, "Кредитор": 2, "Истец": 2, "Ответчик": 2, "Третье лицо": 1 };
  documents.forEach((item) => {
    (item.analysis.parties || []).forEach((party) => {
      const match = parties.find((existing) => samePartyName(existing.name, party.name));
      if (!match) {
        parties.push({ ...party });
        return;
      }
      match.inn = match.inn || party.inn;
      match.snils = match.snils || party.snils;
      if ((rank[party.role] || 0) > (rank[match.role] || 0)) {
        match.role = party.role;
        match.name = party.name;
      }
    });
  });
  return parties;
}

function samePartyName(left, right) {
  const stem = (name) => {
    const token = String(name || "").toLowerCase().replaceAll("ё", "е").split(/\s+/).find((part) => part && !["ооо", "ао", "пао", "зао", "ип"].includes(part)) || "";
    return token.length >= 5 ? token.slice(0, -2) : token;
  };
  const a = stem(left);
  const b = stem(right);
  if (a.length < 4 || b.length < 4) return String(left).trim().toLowerCase() === String(right).trim().toLowerCase();
  return a === b || a.startsWith(b) || b.startsWith(a);
}

function uniqueStrings(values) {
  const seen = new Set();
  return values.filter((value) => {
    const key = String(value).trim();
    if (!key || seen.has(key)) return false;
    seen.add(key);
    return true;
  });
}

function highlight(pageText, quote) {
  const words = quote.split(/\s+/).map((word) => word.replace(/[^\p{L}\p{N}-]/gu, "")).filter((word) => word.length > 1).slice(0, 14);
  if (!words.length) return escapeHtml(pageText);
  const pattern = words.map(escapeRegExp).join("[\\s\\S]{0,8}");
  const match = pageText.match(new RegExp(pattern, "i"));
  if (!match || match.index === undefined) return escapeHtml(pageText);
  const start = match.index;
  const end = start + match[0].length;
  return `${escapeHtml(pageText.slice(0, start))}<mark class="hit">${escapeHtml(pageText.slice(start, end))}</mark>${escapeHtml(pageText.slice(end))}`;
}

function linkifyArticles(text) {
  const pattern = /(?:ч\.\s*\d+\s+|п\.\s*[\d–\-]+\s+|абз\.\s*\d+\s+)*ст\.\s*[\d.]+(?:\s*(?:,|и)\s*[\d.]+)*(?:\s+(?:ФЗ-\d+|АПК\s*РФ|ГК\s*РФ|КоАП\s*РФ|ФЗ-229))?/gi;
  let html = "";
  let last = 0;
  for (const match of text.matchAll(pattern)) {
    html += escapeHtml(text.slice(last, match.index));
    html += consultantLink(match[0]);
